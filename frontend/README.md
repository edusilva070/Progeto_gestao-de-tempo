# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

# ⚡ TimeFlow Pro - Gestão de Tempo Inteligente

O **TimeFlow Pro** é uma aplicação Full-Stack desenvolvida para resolver um problema real de quem concilia **trabalho e universidade**: a fadiga mental e a paralisia de escolha na hora de organizar o dia.

Diferente de listas de tarefas comuns, o TimeFlow Pro inova ao trazer um **Filtro de Energia e Contexto (Smart Filters)**, sugerindo a atividade ideal com base em _onde o usuário está_ (Casa, Faculdade, Trabalho, Trânsito) e _quanta energia ele tem disponível_ (Alta ou Baixa).

---

## 🚀 A Inovação: Filtro de Contexto & Energia

Estudantes trabalhadores muitas vezes ficam perdidos no "limbo" entre os turnos. O algoritmo deste app ajuda a tomar decisões rápidas:

- **Exemplo:** Se você está no **Trânsito** e com **Baixa Energia**, o app filtra blocos leves como _"Ouvir podcast da matéria"_ ou sugere descanso, evitando o estresse.
- **Identidade Visual Dinâmica:** Cada bloco possui uma cor baseada em sua categoria (🔵 Trabalho, 🟢 Tempo Livre, 🔴 Prazos/Urgências, 🟡 Aulas/Reuniões) com um design interativo e moderno em tons de azul e branco.

---

## 🛠️ Tecnologias Utilizadas

### Front-end

- **React.js** (com Vite)
- **Tailwind CSS** (Design moderno e interativo)
- **Lucide React** (Ícones premium)
- **Axios** (Conexão com a API)

### Back-end

- **Node.js**
- **Express.js**
- **JSON File System** (Armazenamento leve e local)
